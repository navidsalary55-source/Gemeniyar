# هوش مصنوعی هوشیار (AIHub)

۱۴ ابزار هوش مصنوعی در یک اپ اندروید (چت، صوت، تصویر، ترجمه، ساخت سایت و ...).

## ساخت APK
1. همه‌ی محتوای این پوشه (شامل `.github`، `app` و `tools`) را در ریپوی GitHub آپلود کن.
2. اگر ریپو فایل `.gitattributes` دارد (قاعده‌ی LFS)، حذفش کن.
3. تب Actions ← «Build APK» ← آرتیفکت **AIHub-apk**.

عکس‌ها به‌صورت متن (base64) داخل پروژه‌اند تا آپلود خراب نشود؛ آیکون برنامه هم موقع بیلد از `tools/*.b64` ساخته می‌شود.

## سرویس هوش مصنوعی
در تنظیمات اپ: Groq (پیشنهادی)، Cerebras، OpenRouter، Mistral، Gemini یا Pollinations (بدون کلید).

## تازه در نسخه ۱.۵
- راهنمای متنی و ویدیوی آموزشی برای هر بخش (دکمه‌ی ⓘ بالای هر صفحه، و منو ← «راهنما و آموزش»). ویدیوها داخل `app/src/main/assets/videos/` به‌صورت base64 هستند.
- چت صوتی کامل: پیام صوتی، تشخیص گفتار با Whisper (کلید Groq) یا گوگل گوشی، و جواب با صدای آنلاین طبیعی (یا صدای گوشی).
- تغییر صدا: حالت «صدای دیگر» (خواندن جمله با صدای آماده‌ی هوش مصنوعی) کنار افکت‌ها.
- جایگزینی خودکار سرویس وقتی کلید/سهمیه‌ی یکی جواب نداد، و کلید اختیاری Pollinations برای تصویر و صدای پایدارتر.

## نسخه ۱.۶ — تاریخچه
هر کاری که در برنامه انجام شود (چت، چت صوتی، ترجمه، نوشتن، آهنگ، سایت، کاراکتر سه‌بعدی، نقاشی، متن به صدا، صدای دیگر، ویرایش تصویر، گفتار به ویدیو) خودکار ذخیره می‌شود. از منو ← «تاریخچه» یا آیکون ساعت بالای هر بخش قابل دیدن، کپی، اشتراک، ذخیره و حذف است.
